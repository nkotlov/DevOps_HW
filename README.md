# Домашние работы по DevOps

**Студент:** Котлов Никита  
**Группа:** 11-306

## Описание

В данном репозитории представлены выполненные домашние работы по DevOps.  
Каждая работа находится в отдельной папке и содержит необходимые файлы, скрипты, конфигурации, README.md с описанием выполнения, а также скриншоты проверки результата.

## Список домашних работ

| № | Папка | Тема |
|---|---|---|
| 1 | `dz1-bash` | Bash-скрипт для настройки группы `dev`, sudo-прав, рабочих директорий пользователей, ACL-доступа и логирования |
| 2 | `dz2-ansible-playbook` | Ansible playbook для создания пользователя, настройки sudo, SSH-ключей, отключения SSH-пароля и создания директории в `/opt` |
| 3 | `dz3-ansible-roles` | Ansible roles с разделением задач по ролям и тестированием через Molecule + Docker |
| 4 | `dz4-dockerfile-web-db` | Dockerfile для сборки образа с Nginx и PostgreSQL |
| 5 | `dz5-docker-compose-web-db` | Docker Compose для разворачивания Nginx и PostgreSQL в одной bridge-сети |
